Toma 0.2.0 trae el trabajo de cientos de mejoras del editor: más formatos de intercambio y de imagen, un campo hexadecimal para los colores y un trabajo más sólido con archivos dañados.
*Toma 0.2.0 brings hundreds of editor improvements: more interchange and image formats, a hex field for colours, and sturdier handling of damaged files.*

> [!IMPORTANT]
> Toma está en una fase temprana: guarda a menudo y avísanos de lo que falle.
> Toma is at an early stage: save often and tell us what goes wrong.

## Español

### Novedades
- **Color en hexadecimal:** los parámetros de color de Controles de efectos tienen un campo hexadecimal.
- **Texto en varios clips:** un cambio en una propiedad de texto del panel Propiedades se aplica a todos los clips de texto seleccionados.
- **Más formatos:** DNG (opcodes, teselas con pérdida y metadatos), AAF, OMF, FCP7, FCPXML, colores de marcadores OTIO, ALE, EDL, TGA, DPX, EXR, WAV, Y4M, ProRes y DNx.
- **Códecs:** decodificación de HE-AAC (SBR) y codificación H.264.
- **Bosnio** como idioma de la interfaz, y un adaptador gráfico por software de reserva cuando no hay GPU.

### Correcciones
- Los archivos de proyecto se limitan a 256 MiB en cada lectura, y el XML de intercambio tiene un límite de anidación y de nodos, de modo que un archivo dañado da un error en lugar de bloquear la app.
- Menús contextuales, la regla y «Mostrar en el proyecto» funcionan como se espera.

### Notas
- Si macOS bloquea la app la primera vez, haz clic derecho en Toma dentro de Aplicaciones, elige **Abrir** y confirma. El DMG no está firmado ni notarizado.

## English

### What's new
- **Hex colours:** colour parameters in Effect Controls have a hex field.
- **Text across clips:** a text property change in the Properties panel applies to every selected text clip.
- **More formats:** DNG (opcodes, lossy tiles and metadata), AAF, OMF, FCP7, FCPXML, OTIO marker colours, ALE, EDL, TGA, DPX, EXR, WAV, Y4M, ProRes and DNx.
- **Codecs:** HE-AAC (SBR) decoding and H.264 encoding.
- **Bosnian** as an interface language, and a software graphics adapter fallback when there is no GPU.

### Fixes
- Project files are capped at 256 MiB on every read, and interchange XML has bounded nesting and node counts, so a damaged file reports an error instead of locking up the app.
- Context menus, the ruler and Reveal in Project behave as expected.

### Notes
- If macOS blocks the app the first time, right-click Toma in Applications, choose **Open**, and confirm. The DMG is not signed or notarized.
