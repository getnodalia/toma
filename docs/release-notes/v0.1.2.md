Toma 0.1.2: buscar actualizaciones ya no falla con «http status: 403» cuando GitHub limita las consultas.

*Toma 0.1.2: checking for updates no longer fails with "http status: 403" when GitHub limits requests.*

## Español

### Correcciones

- Buscar actualizaciones ya no termina en «Could not reach GitHub Releases: http status: 403». GitHub solo responde unas pocas consultas por hora desde cada red, compartidas por todas las apps que la usan. Ahora Toma guarda la última lista de versiones y, al volver a buscar, solo pregunta si ha cambiado, una pregunta que no gasta ese límite.
- Si el límite se agota igualmente, Toma sigue sabiendo cuál es la versión más nueva y ofrece abrir su página. Si no puede saberlo, explica en tu idioma qué ha pasado y cuándo volver a intentarlo.
- Descargar una actualización ya no se corta a mitad (por ejemplo al 75 %) con «timeout: receive body». Solo se detiene si la conexión deja de responder, y al reintentar sigue desde donde iba.

## English

### Fixes

- Checking for updates no longer ends in "Could not reach GitHub Releases: http status: 403". GitHub answers only a few requests an hour from each network, shared by every app on it. Toma now keeps the last list of releases and, when it checks again, only asks whether it changed, a question that does not spend that limit.
- If the limit runs out anyway, Toma still knows which version is newest and offers to open its page. If it cannot tell, it says in your language what happened and when to try again.
- Downloading an update no longer stops part way (at 75 %, say) with "timeout: receive body". It stops only if the connection stops responding, and a retry carries on from where it was.
